### What I learned

This was a really heavy challenge compareed to previous ones by a distance. I learnt a lot of css and how flexible css really is.

I learnt for the first time that my deisgn has to be responsive and how I can use ```@media``` queries for that.

I learnt how to align flexbox children into a grid-like alignment with the
```css
.values >* {
  width: 100px;
  margin-right: auto;
}
```
I couldn't explain to you how that works though lol.
